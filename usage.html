效率工具

功能怎么用说明
番茄钟（25 分钟）按住小猴 0.65 秒 / 菜单 / Ctrl+Shift+T专注时变思考脸，每分钟报剩余；结束弹系统通知
今日待办 / 每日任务菜单「今日待办…（编辑）」没做完会自动顺延到明天，完成后不再出现（不再"每天重置勾选"）；分「必须完成 / 有余力再做」，可设预计分钟与截止日期；逾期、今天截止、顺延天数都会标出来；双击标题可改
未完成提醒菜单「未完成提醒（每 10 分钟）」开关 / 「现在提醒一次」/ 「今天不再提醒」每 10 分钟用气泡列出还没做完的任务；只在 08:00–23:00 提醒，全部完成即自动停；当天可静音，次日恢复
剪贴板历史Ctrl+Shift+V最近 50 条；可搜索，↑↓ 选择、Enter 复制回剪贴板；只存内存、重启清空
系统监控Ctrl+Shift+M气泡显示 CPU、内存、网络 ↓/↑ 速度
课程表 / 日程Ctrl+Shift+K加每周课程或一次性日程，提前 N 分钟气泡提醒；「查看今日课程」看当天课表

AI 功能

功能怎么用说明
AI 设置 第一次必做Ctrl+Shift+U → 点「一键自动接好」自动探测本机可用接口（Codex 中转 / Ollama / LM Studio），探到就接好并测一次。也可以手动填 Base URL（到 /v1 为止）+ API Key
AI 对话Ctrl+Shift+A需 Key 任意 OpenAI 兼容接口
名片识别图片拖到小猴身上 / 菜单「识别名片图片…」需 Key + 视觉模型 抽取姓名/公司/职位/电话/邮箱/地址/网址，可复制 JSON
语音朗读（TTS）AI 设置里勾选「语音朗读」免费 用 Windows 系统语音；没声音就去系统设置装中文语音
每日早报Ctrl+Shift+R 或菜单无需 Key 天气 + 一条热点；设好时间会每天自动弹
PDF 论文解析Ctrl+Shift+D 或 菜单「解析 PDF 论文…」，也可把 PDF 拖进窗口无需 Key 也能跑 提炼 研究问题 / 研究方法 / 主要结论 / 关键贡献，可看 JSON、复制、导出 Markdown。限制：PDF ≤ 30MB、≤ 60 页、需含可选中文字（扫描件要先 OCR）。配了 Key 用 AI 读得更准，没配就用本地规则抽取

常见问题

现象原因 / 解决
改了代码没生效单实例锁：要先右键「退出」再重新打开，直接双击只会聚焦旧实例
AI 对话报错打开「AI 设置」点「测试连接」看错误码：auth Key 错或过期、model-not-found 模型名不可用、network 没网或代理没开、timeout 接口太慢
名片识别没结果DeepSeek-V4.1-Flash 是纯文本模型，不支持图片输入；名片识别需要「AI 设置」里点「改用其他模型」换成视觉模型
TTS 没声音系统没装中文语音：Windows 设置 → 时间和语言 → 语音，添加中文
论文解析报「可能是扫描件」PDF 里没有可选中文字（图片版扫描件），要先做 OCR；不配 Key 用规则抽取也能出结果
论文标题/作者识别成文件名版式太特殊（多栏、封面页信息混杂）时启发式会退化；配了 AI 接口后走模型路径更稳
网速显示 N/APowerShell 的 Get-NetAdapterStatistics 不可用；CPU/内存仍然正常
早报天气/热帖失败网络或代理问题；天气用 wttr.in、热帖用 V2EX，可隔天再试
配置存在哪%APPDATA%\monkey-pet\settings.json（含 API Key，注意别外传）
没有匹配的内容，换个关键词试试～
